# DocSanitize

A private, open-source PDF and image toolkit that runs entirely in your browser. Inspect and strip hidden metadata, organize pages, convert, sign and secure documents — nothing is ever uploaded.

> **Status:** early development. The app shell is in place; tools are being added milestone by milestone.

## Development

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static export to ./out
```

The build is a fully static site (`output: "export"`) that can be hosted on any static file host.
